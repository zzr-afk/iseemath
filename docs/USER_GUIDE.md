# iseemath 用户指南

本文面向实际使用工具的策划。JSON 字段与公式的严格定义见 [项目格式规范](PROJECT_FORMAT.md)；希望让 AI 生成/修改项目时见 [AI 工作流指南](AI_GUIDE.md)。

## 1. 启动与项目

```bash
pnpm install
pnpm dev
```

Windows 用户也可以直接双击项目根目录的 [start.bat](../start.bat)：首次运行自动安装依赖，随后启动开发服务器并打开浏览器；`start.bat --no-open` 只启动、不打开浏览器。

`pnpm dev` 会启动本地静态站点，地址以终端输出为准。首次打开会自动创建一个空项目。

顶栏包含品牌、当前项目与操作：

- **项目**：新建项目、打开本地项目、导入项目 JSON、导出项目 JSON。
- **保存状态标签**：已保存 / 保存中 / 只读 / 保存冲突 / 保存失败。
- **撤销 / 重做**：撤销栈只记录项目文档编辑，最多 100 条；折叠状态、视口、日志行数据编辑不进撤销。
- **问题标签**：显示当前公式与结构错误数量；点它会进入「关系结构」工作区，下方「问题」面板列出具体节点和错误。

顶栏下方是四个工作区标签，内容是单列排布的卡片面板（从上往下滚动，不再有常驻左右栏）：

- **建模画布**：画布、变量、折叠包、属性、使用顺序。
- **关系结构**：每行定义一条数值关系，公式写在这里，画布箭头自动生成；下方是「问题」面板。
- **日志分析**：导入、预览、聚合与图表。
- **对比分析**：目前为占位页。

自动保存使用 IndexedDB，编辑后约 500ms 落盘。同一项目同时打开两个标签页时，只有主标签页可编辑，另一个显示只读横幅；主标签页关闭后会自动接管。

## 2. 建模画布

### 2.1 节点类型

| 节点 | 用途 | 是否参与计算 |
|---|---|---|
| 变量 | 一个数值，或一个引用其它变量的公式 | 是 |
| 分组 | 逻辑分类/归属，便于组织 | 否 |
| 数据表 | 同一类型的多行数据共享字段与派生公式 | 是（批量） |
| 折叠包 | 把一组变量折叠成一张卡片 | 否（只影响显示） |

主流程只有一种建模节点：**变量**。所有数值量——自由输入和推导结果——在画布上使用同一种卡片，只显示名字、当前值和单位；自由输入画成虚线边框（来源量），推导量画成实线边框。点击画布左上角「变量」或「关系结构」右上角的「变量」新建，默认是值为 0 的自由输入。变量之间的关系统一写在「关系结构」工作区里，画布上的蓝色箭头由关系自动生成。

「分组」和「数据表」收在左上角「更多」里，分别用于组织和批量数据；数据表需要先有日志数据集，详见 §5。双击空白处不会新建。

每个节点有：

- **展示名**：卡片上显示的名字，可重复。
- **符号名**：公式中引用的名字，必须符合标识符规则（中文可用），同类节点内不区分大小写唯一。
- **归属上级**：最多一个，可以是分组或变量；层级不能成环。
- **标签**：自由分类，可多个。

### 2.2 三类关系

画布上同时存在三种边，含义完全不同：

1. **归属边（灰色虚线，上/下端口）**
   - 表达“这个节点属于哪个分组/上级”，最多一条。
   - 拖节点底部归属端口到目标顶部归属端口，或在「属性」面板里改「归属上级」，或在「变量」面板中拖拽。
   - 不参与计算。

2. **计算依赖边（蓝色实线，左右端口）**
   - 由公式派生：公式里引用了一个变量，就出现一条依赖边。
   - 可以直接连线：从源变量右侧蓝色端口拖到目标变量左侧蓝色端口。工具会在目标公式末尾追加 `+ 源变量名`，并自动切到「关系结构」定位到目标行，再按需把 `+` 改成 `*`、`-` 等运算符。
   - **点击蓝色箭头**会切到「关系」面板并高亮对应的目标行，方便直接改公式。
   - 删除依赖边要改公式或删除关系；选中依赖边按 Delete 只会提示，不会直接删。
   - 如果连线会形成循环引用，命令会拒绝并报错。

3. **影响边（琥珀色点线，右侧侧边端口）**
   - 表达设计语义上的“A 影响 B”，例如“版本平衡影响最终伤害”。
   - 从源节点右侧的影响输出端口拖到目标节点左侧的影响输入端口。
   - 可以多对多、可以成环，不参与求值。
   - 选中边后按 Delete 删除；也可以在「属性」面板查看影响关系。

工具栏右侧的「全部 / 归属 / 依赖 / 影响」用于过滤显示哪类边。折叠包收起时，跨包边会显示为带 `×N` 计数的代理边；展开后才恢复具体成员之间的边。

### 2.3 变量、输入与关系结构

「关系结构」工作区是定义数值关系的主入口。每一行对应一个数值量：

- **左侧**：展示名与符号名；点击名字会在画布中选中该变量。
- **中间**：自由输入显示数值框和「写关系」按钮。点「写关系」后，这个量变成推导量，当前值会成为公式的初始内容。
- **中间（推导量）**：结构化公式编辑器。上方每个「局部量」占一行，由名字、表达式和这一行的实时值组成：
  - 名字默认按 a、b、c… 分配，可以改成中文；点行尾 × 删除，点「结果」行尾 + 新增。
  - 局部量**只在这一条关系内有效**。不同关系可以重复使用 a、b、c，不会互相冲突，也不需要为中间步骤新建全局变量。
  - 保存时会自动写成等价的 `let a = …; let b = …; 结果` 公式；项目 JSON 里保存的仍然是这份文本，因此导入导出、依赖图和计算行为都不变。
  - 改名一个局部量会自动更新它**之后**的表达式和「结果」行中的引用；它自己那一行的表达式和函数名不会被误改。
  - 下方「来源」列出结果或局部量真正引用到的全局变量。
- **右侧**：当前计算结果；有错误时显示红色原因，鼠标悬停可看全文。
- **行尾断开按钮**：删除关系，把当前结果冻结成固定值（仍是一条可撤销记录）。

点画布上的蓝色依赖箭头会切换到这个工作区并高亮对应行。公式编辑器支持变量名、函数、曲线/表格调用；`Ctrl+Space` 打开补全，`Enter` 提交，`Shift+Enter` 换行。

也可以直接手写 `let` 文本（例如从旧项目导入的公式）；编辑器会把它拆成同样的局部量行，提交后仍按统一的 `let …;` 形式保存。

```text
let a = 基础主属性 * (1 + 主属性提成);
let b = 最终主属性 + 100;
a * b
```

- **属性面板**：在「建模画布」下方的「属性」面板选中变量后，显示当前值和只读的关系式；点「在关系结构中编辑」会跳到对应关系行。自由输入可以直接在属性面板改「值」。
- **用途**：输入 / 中间量 / 输出，仅作为分析元数据，不改变计算。约定 `输入` 用于没有公式依赖的自由输入，供后续对比分析识别可覆盖的输入。
- **单位、精度、颜色、描述**：展示与组织用途。

公式结果会实时刷新。解析失败、未知变量、除零、循环引用等会：

- 在卡片上显示红色错误；
- 在「关系结构」页下方的「问题」面板列出节点与错误；
- 让下游节点显示错误，而不是沿用旧值。

公式语法速查：

```text
算术：+ - * / % ^
比较：< <= > >= == !=        （不能链式，如 1<2<3 请写 1<2 and 2<3）
逻辑：and or                   （要求布尔值，短路求值）
分支：条件 ? 值1 : 值2          （只求选中分支）
函数：abs ceil floor round sign sqrt exp ln log log10 pow min max clamp lerp isNaN if
常量：PI E true false
局部变量：let a = 表达式; let b = 表达式; 结果表达式
```

完整优先级与语义见 [PROJECT_FORMAT.md §6](PROJECT_FORMAT.md#6-公式语言)。注意：`not` 未实现，不要使用；自动补全里可能出现它，但求值会报未知函数。

### 2.4 重命名与删除

- 在「属性」面板改「符号名」会同步更新公式引用；改名是单条撤销记录。
- 删除节点时：
  - 其直接子节点提升到它的上级；
  - 从所有折叠包成员中移除；
  - 删除所有触碰它的影响边；
  - 公式中对该节点的引用保留，并显示“未知变量”，不会自动改绑。
- 变量名不能与任一数据表字段名冲突；数据表字段名也不能与全局变量、内置函数/常量冲突（命令会拒绝）。
- 删除被公式引用的变量后，再建同名变量不会自动恢复引用；需要手动改公式。

### 2.5 折叠包

折叠包是**纯视图**：不改变公式依赖、不参与计算、汇总值不能被公式引用。适合把“攻防乘区 / 技能乘区 / 元素乘区”等一组变量收起来。

1. 多选两个及以上常量/公式变量（Shift 或框选）。
2. 点击工具栏「打包」。
3. 填名称，选择汇总方式：仅显示数量、求和、乘积、平均、最小、最大、显示指定成员的值。
4. 打包后默认收起；「变量」面板旁的「折叠包」面板可以逐个展开/收起，互不影响。

规则与行为：

- 成员只能是常量或公式变量；曲线/表格、分组、数据表不能打包。
- 一个变量最多属于一个折叠包；不支持包嵌套。
- 删除成员节点会同时把它移出包；成员删空时包自动解散。
- 选中折叠卡片后按 Delete 只**解散包**，不会删除成员。
- 汇总值只为展示；若某些成员错误，聚合汇总显示“—”，并显示错误数。
- 折叠时跨边界边会聚合为代理边；组折叠优先于包折叠，被组收起隐藏的成员不会随包拖动。

## 3. 日志分析

切换到「日志分析」：

### 3.1 导入数据

点击「导入」，选择 CSV 或 JSONL（也接受 `.txt` / `.log`）：

- 单文件上限 **50MB**；数据只保存在本机 IndexedDB。
- 编码：自动检测 / UTF-8 / GB18030、GBK / UTF-16 LE。中文日志优先确认编码。
- 分隔符：自动 / 逗号 / 制表符 / 分号 / 竖线。
- 首行是表头：可关闭。
- 解析预览后可逐列覆盖字段类型：文本 / 数值 / 日期；日期列按浏览器本地时区解析。
- 点「保存到项目」。大于 1MB 的文件在后台 Worker 解析，主界面不冻结。

CSV 会处理引号内逗号/换行、转义引号、CRLF、BOM；JSONL 每行一个对象，坏行会跳过并统计。空单元格记为 null，数值列中无法解析的单元格记为 bad，两者分开计数，不污染数值。

### 3.2 数据集操作

选中左侧数据集后：

- **数据预览**：前 100 行；顶部显示行列数、编码、分隔符、空值/坏值数量。
- **聚合分析**：见下节。
- **替换数据源**：为同一个数据集换文件。成功后保留数据集 id，尽量保留列映射；列缺失/类型变化会把相关分析视图和数据表字段标记为失效。
- **解析设置**：修改编码、分隔符、表头、时区、日期格式；保存后触发重建。重建完成前该数据集不可运行。
- **重建**：重新读取原始文件并解析。
- **删除**：删除数据集；引用它的分析视图会失效，数据文件在宽限期后回收。

刷新页面后，数据集先显示已有元数据，后台重建列式数据；重建完成前显示“待就绪”。

### 3.3 聚合与图表

「聚合分析」中可以组合：

- **筛选**：等于、不等于、大于/大于等于、小于/小于等于、属于（逗号分隔）、包含、为空、不为空。
- **分组**：最多 3 个字段；可选时间分桶（原始值 / 分钟 / 小时 / 天 / 月）。
- **指标**：计数、求和、平均、最小、最大、中位数、P90、P95。
- **图表**：折线图或柱状图。
- **保存视图**：把筛选、分组、指标、图表保存为左侧「分析视图」，之后一键重新应用。

视图保存时会记录所引用列的结构哈希。数据集删除、列缺失或列类型变化后，视图显示「失效」，不能运行；当前版本没有“修复视图”按钮，需要重新创建视图。

## 4. 数据表（批量建模）

数据表用于“同类型的 N 条实例共享一套字段和公式”，例如 100 行怪物数据，不需要在画布上画 100 个节点。

### 4.1 创建与绑定

1. 先在「日志分析」导入一个数据集（CSV/JSONL）。
2. 回到「建模画布」，点击工具栏「数据表」。
3. 工具会绑定第一个可用数据集，并把所有数据集列自动创建为输入字段，字段名自动去重并避开全局变量名。
4. 数据表卡片显示“行数 · 字段数 · 派生列数”；双击卡片打开编辑器，属性面板里也有「打开数据表编辑器」。

### 4.2 字段编辑

编辑器顶部可以选择/切换绑定的数据集。字段分两类：

- **输入列**：映射到数据集中的一列。可改字段名、类型、映射列。类型为数值/日期时参与数值公式；文本/枚举只展示。
- **派生列**：只能用行作用域公式计算，输出必须是数值。

派生列公式的解析顺序：

1. 先匹配当前表的字段名（行内值）；
2. 再匹配全局变量、曲线、表格。

例如：

```text
HP * ATK / (DEF + 100) * 伤害倍率
```

其中 `HP`、`ATK`、`DEF` 是当前行字段，`伤害倍率` 是全局常量。派生列之间可以互相引用，工具会做列级依赖排序与循环检测；循环中的列显示“派生列存在循环引用”，预览为“—”。

规则：

- 字段名在表内唯一（不区分大小写），且不能遮蔽全局变量、内置函数/常量。
- 输入字段的映射列必须存在且类型兼容；否则字段标红、表标记“数据缺失”，禁止求值。
- 派生列只能输出数值；引用文本字段会报错。
- 空值/坏值在该行参与计算时会报“该行为空”；结果按行独立，某行错误不会阻断其它行。

### 4.3 预览与数据缺失

编辑器下方显示前 **50 行**的输入列与派生列结果，方便快速验算。这里只读，不提供逐行编辑；需要改数据请重新导入或替换数据源。

如果数据集来自“仅元数据导入”或原始文件丢失，卡片与编辑器会提示“数据缺失/数据集不可用”。在「日志分析」里对同一数据集执行「替换数据源」后，字段映射会按列 id 自动恢复；列 id 不匹配的字段需要手动重选。

### 4.4 与标量公式的边界

- 数据表派生列可以引用全局常量/公式/曲线/表格；
- **标量公式不能直接引用数据表字段**，也没有隐式聚合；
- 画布上只会出现“全局变量 → 数据表”的类型级依赖边，不会为每一行画边。

## 5. 导入与导出

顶栏「项目 → 导出项目 JSON」导出当前项目。文件包含：

```json
{
  "format": "numlab",
  "schemaVersion": 1,
  "appVersion": "0.1.0",
  "exportedAt": 0,
  "project": { ... },
  "viewState": { ... },
  "comparisonRuns": []
}
```

导出**不包含日志原始文件与解析结果**，只含数据集元数据（文件名、列结构、哈希、行数等）。

「项目 → 导入项目 JSON」：

- 接受上述信封，也接受直接的项目对象。
- **总是创建一个新项目并分配新项目 id**，不会覆盖现有项目。
- 所有数据集被标记为不可用，`blobKey` 清空；
- 所有分析视图和对比配置被标记为失效，原因为 `data-unavailable`；
- 数据表标记数据缺失；
- 导入后需要到「日志分析」重新导入/替换数据源，再重建分析视图。
- 导入前会做 schema 与结构不变量校验；第一个错误会直接提示。
- 文件上限 50MB，最多 10,000 节点、50,000 条影响边、500 个折叠包、单条公式 8KB。

保存冲突时，顶栏「项目」菜单会出现「导出本地草稿」和「放弃本地改动并重新加载」。

## 6. 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Delete` / `Backspace` | 删除选中节点或边；选中折叠包卡片时解散包 |
| `Ctrl/Cmd + Space` | 公式编辑器补全 |
| `Shift` / `Ctrl` + 点击、拖框 | 多选 |

输入框聚焦时 Delete 不会删除节点。

## 7. 当前限制

- **对比分析**：M4 才开放，当前页面为占位。
- **曲线/表格节点**：JSON 格式与求值器已支持，但界面暂不提供创建/编辑入口。通过 JSON 导入的曲线/表格可以参与公式。
- **数据表行数据**：只读预览；没有手工录入/单元格编辑，没有 Excel 导入。
- **分析视图修复**：失效后只能重新创建，不能就地修复。
- **AI**：应用内不调用 AI；AI 通过导出/修改/导入 JSON 工作，见 [AI 工作流指南](AI_GUIDE.md)。
- **导入粒度**：只能导入完整项目，没有“片段导入”或“追加节点”。
- **折叠包**：不支持嵌套；折叠状态下不能在成员之间新建关系，需要先展开。
- **导入折叠状态**：导入项目时，文件里的 `viewState`（折叠包默认收起）不会立即应用到当前画布，需要手动切换一次开关；项目文件本身保留了该状态。
- **多标签页**：同一项目同时只有主标签页可写，其余只读。
- **文件规模**：单文件 50MB；100MB 目标在 M4 验收。

## 8. 常见问题

**公式报“未知变量”**
检查符号名是否改过、变量是否被删除、名字是否与函数/保留字冲突。分组名、数据表名、折叠包名不能作为数值引用。

**节点显示循环引用**
公式依赖成环。依次检查环上的公式，或看「关系结构」页下方的问题面板。数据表则检查派生列之间的引用。

**数据表显示“数据缺失”**
数据集被删除、原始文件丢失，或仅通过 JSON 导入。去「日志分析」替换数据源，或重新导入文件。

**分析视图“失效”**
数据集列结构变化（列被删/类型改变）或数据源不可用。重新创建视图；如果是替换数据源导致的列变化，先检查解析设置与表头。

**页面只读**
另一个标签页正在编辑同一项目。关闭对方标签页后本页会自动接管。

**导入项目失败**
提示的是第一个 schema/结构错误。常见原因：节点名不是合法标识符、同类型节点重名、上级/影响边端点不存在、折叠包成员不存在或不可打包、汇总成员不在包内。详见 [项目格式规范 §9](PROJECT_FORMAT.md#9-导入校验与导入时改写)。
